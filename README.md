# 🛒 Modern E-Commerce Store (ShopNexus)

A full-stack modern eCommerce web application built with a powerful MERN stack architecture. This project includes a fully functional frontend, secure backend APIs, authentication system, product management, and order processing.

## 📌 Features

### 🔐 Authentication & Authorization

* User registration & login (JWT-based)
* Protected routes
* Password reset functionality
* Role-based access (Admin/User)

### 🛍️ Product Management

* View all products
* Product filtering & search
* Category-based browsing
* Product details page
* Reviews & ratings system

### 🛒 Shopping Experience

* Add to cart
* Update cart items
* Wishlist functionality
* Checkout system

### 💳 Orders & Payments

* Create orders
* Order history
* Payment integration (Stripe)
* Order status tracking

### 🛡️ Security Features

* Rate limiting
* Data sanitization
* Helmet security headers
* HPP protection

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Modern-eCommerce-Store.git
cd Modern-eCommerce-Store
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:5173
```

Run backend:

```bash
npm run dev
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
